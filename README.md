# 🎬 AI Short Video Workflow Agent (短剧自动化创作流水线)

本项目是一套专为短剧创作打造的 **AI Agent 与提示词规范库**。通过结构化的 Prompt 编排，实现从“小说/原文 ➔ 格式化剧本 ➔ 资产提取 ➔ 分镜拆解 ➔ 生图/生视频提示词”的全流程本地/云端纯文本协作。

## 📁 目录结构
- `prompts/`: 包含编剧、制片助理、分镜师、提示词专家的核心 Prompt。
- `skills/`: 包含角色、道具、场景、视频提示词的具体细节规范。

## 🚀 如何使用
1. 将 `prompts/` 中的对应角色 Prompt 发给大模型（如 ChatGPT / Claude / DeepSeek）。
2. 按照 4 步法流水线依次输入内容，获取纯文本结果并在本地保存。
